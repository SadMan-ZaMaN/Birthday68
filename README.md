# 🎂 Happy Birthday Rajin!

## How to open it on a Mac

1. On this GitHub page click the green **Code** button → **Download ZIP**, then double-click the ZIP to unzip it.
2. Open the unzipped folder and double-click **`Start Birthday.command`**.
   - If macOS says it "cannot be opened" / "unidentified developer": right-click the file → **Open** → **Open**.
     (On newer macOS: System Settings → Privacy & Security → scroll down → **Open Anyway**.)
3. Your browser opens the birthday café automatically. Keep the Terminal window open while you enjoy it.

The first time, it may download a small helper (Node.js, ~40 MB) if your Mac doesn't have it. After that it opens instantly.

### If double-clicking doesn't work

Open the **Terminal** app, type `bash ` (with a space), drag `Start Birthday.command` into the Terminal window, and press **Enter**.
